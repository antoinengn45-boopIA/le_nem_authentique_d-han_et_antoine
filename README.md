# 🍔 HanetAntoine - Foodtech Platform
Bienvenue sur le projet hanetantoine, une solution moderne de Click & Collect conçue pour faciliter la commande en ligne et la gestion de vos plats.

🚀 Fonctionnalités
Menu Interactif : Visualisez les plats disponibles en temps réel.

Click & Collect : Système simplifié pour commander et récupérer vos repas.

Support Client : Formulaire intégré pour les suggestions et questions.

🛠 Stack Technique
Frontend : HTML5, Tailwind CSS

Logique : JavaScript (Vanilla)

Déploiement : GitHub Pages

Formulaire : Tally Integration

⚙️ Installation
Pour cloner et exécuter ce projet localement, suivez ces étapes dans votre terminal :

Bash
# Cloner le dépôt
git clone https://github.com/votre-compte/hanetantoine.git

# Accéder au dossier
cd hanetantoine

# Ouvrir le fichier index.html dans votre navigateur
# Aucune installation complexe n'est requise, c'est un site statique.
📝 Configuration
Ce projet est optimisé pour être hébergé sur GitHub Pages.

Assurez-vous que votre fichier principal est nommé index.html.

Dans les paramètres de votre dépôt (Settings > Pages), vérifiez que la branche main est bien configurée comme source.

💡 Support
Besoin d'aide ? Utilisez le bouton "Contact & Suggestions" directement sur la plateforme pour envoyer vos retours via Tally.
