# hanetantoine

Plateforme simplifiée pour la commande en ligne et le retrait en restaurant.

## 🚀 Fonctionnalités
- Consultation du menu en temps réel.
- Ajout de produits au panier.
- Paiement sécurisé via Stripe.
- Système de gestion des commandes pour le restaurateur.

## 🛠 Stack Technique
- **Frontend:** Next.js, Tailwind CSS
- **Backend:** Node.js, API Routes
- **Base de données:** PostgreSQL avec Prisma
- **Déploiement:** Vercel

## ⚙️ Installation
1. Clonez le projet : `git clone https://github.com/votre-user/votre-repo.git`
2. Installez les dépendances : `npm install`
3. Configurez votre fichier `.env` avec vos clés (Stripe, Database).
4. Lancez le serveur : `npm run dev`
