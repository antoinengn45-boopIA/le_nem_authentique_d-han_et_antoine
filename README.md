# 🍔 HanetAntoine - Plateforme Foodtech

Bienvenue sur la solution de Click & Collect de **hanetantoine**. Ce projet permet de commander en ligne et de recevoir un reçu instantanément par e-mail.

## 🛠 Stack Technique
- **Frontend :** HTML5, Tailwind CSS
- **Logique :** JavaScript (Vanilla)
- **Automatisation e-mail :** EmailJS

## 🚀 Utilisation
1. Accédez au site via le lien GitHub Pages.
2. Ajoutez des articles au panier (limite de 10).
3. Cliquez sur "Envoyer le reçu par mail" pour finaliser.

## ⚙️ Déploiement
Le projet est configuré pour GitHub Pages. Assurez-vous que le fichier `index.html` est bien à la racine du dépôt.
